# ComingUp Today

**One shared view of what's coming up.**

ComingUp Today brings household schedules and everyday coordination into one
place. See Google and iCloud calendars alongside events you create in ComingUp,
keep useful lists, notes, contacts, and recipes, and put the day on a shared
household screen.

It is built for families, co-parents, caregivers, and other people coordinating
busy schedules. Your existing calendars stay in Google or iCloud. ComingUp brings
them together so everyone can see what's ahead.
