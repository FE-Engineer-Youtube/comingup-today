# ComingUp.today

ComingUp.today is a shared scheduling and calendar aggregation app for families
and small teams.

It provides a single, read-only view of what’s coming up across multiple people
and multiple calendars, helping reduce miscommunication and last-minute surprises.

## Why it exists

ComingUp.today was built to solve a practical problem: coordinating busy schedules
without constantly asking, “What do you have going on?”

The focus is on visibility and shared awareness rather than replacing existing
calendar tools.

## Built for households and small teams

The app is designed for:
- Families with multiple schedules to coordinate
- Small teams that need shared visibility without shared editing
- Non-traditional or fast-changing schedules

Events from authorized external calendars (such as Google Calendar) can be viewed
together alongside local events in one place.

## Shared display friendly

A core use case is a shared screen in a central location (for example, a kitchen
display), while still working well on phones, tablets, and desktops.

## Privacy-first by design

- Read-only access to connected calendars
- Visibility controls per workspace
- Integrations can be disconnected at any time

ComingUp.today is not intended for storing or managing protected health
information (PHI). Sensitive medical details should not be added to event titles
or notes.
