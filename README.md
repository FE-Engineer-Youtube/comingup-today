# ComingUp Today

**One shared view of what's coming up.**

ComingUp Today brings household schedules and everyday coordination into one
place. See Google and iCloud calendars alongside ComingUp events, keep useful
lists, notes, contacts, and recipes, and put the day on a shared household screen.

It is built for families, co-parents, caregivers, and other people coordinating
complex schedules. Connected calendars stay read-only; ComingUp-owned information
can be created and managed in the app and through supported AI tools.
